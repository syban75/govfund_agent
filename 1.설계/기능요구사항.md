## 2.2 기능 요구사항

| ID     | 기능           | 요구사항                                                            | 우선순위 | 기타                     |
| ------ | ------------ | --------------------------------------------------------------- | ---- | ---------------------- |
| GF-001 | 사용자 상담       | 자연어 기반으로 정부 지원사업 상담 기능을 제공한다.                                   | 필수   |                        |
| GF-002 | 기업정보 관리      | 지역, 업종, 설립일, 매출, 종업원 수, 기업규모 등 기업정보를 관리한다.                      | 선택   | 사용자 정보 관리 추후에          |
| GF-003 | 지원사업 검색      | 키워드, 기관, 지역, 지원분야, 신청기간 등을 기준으로 지원사업을 검색한다.                     | 선택   | 검색 기능도 추후에             |
| GF-004 | 맞춤 지원사업 추천   | 기업정보와 지원조건을 분석하여 적합한 정부 지원사업을 추천한다.                             | 필수   |                        |
| GF-005 | 지원자격 분석      | 기업정보와 공고문의 지원대상 및 제외조건을 비교하여 지원 가능성을 분석한다.                      | 선택   | 1차는 질문의 키워드 가지고 있으면 추천 |
| GF-006 | 지원금 분석       | 정부지원금, 지원비율, 자기부담금 등 지원규모를 분석한다.                                | 필수   |                        |
| GF-007 | 일정 분석        | 신청 시작일, 마감일, 사업기간 등 주요 일정을 분석한다.                                | 필수   |                        |
| GF-008 | 제출서류 분석      | 공고문에서 신청에 필요한 제출서류를 추출하고 안내한다.                                  | 필수   |                        |
| GF-009 | 공고문 요약       | PDF, HWP, HWPX 등 정부 지원사업 공고문을 자동으로 요약한다.                        | 선택   | llm 요약하면 되지만 추후에       |
| GF-010 | RAG 검색       | Vector DB 기반으로 관련 공고문과 근거 문서를 검색한다.                             | 필수   |                        |
| GF-011 | Advanced RAG | Hybrid Search, Rerank, Context Compression을 적용하여 검색 정확도를 향상한다.  | 필수   |                        |
| GF-012 | AI Agent     | LangGraph 기반으로 상담 Workflow를 구성하고 상태를 관리한다.                      | 필수   |                        |
| GF-013 | Tool Calling | Agent가 기업마당, 나라장터, RAG 검색 등 필요한 Tool을 자동 선택·호출한다.               | 필수   | RAG만 필수, 나머지는 선택       |
| GF-014 | 답변 생성        | LLM을 이용하여 검색된 근거를 기반으로 상담 답변을 생성한다.                             | 필수   |                        |
| GF-015 | 근거 및 출처      | AI 답변에 사용된 공고명, 기관, 원문 URL 등 근거 Source를 제공한다.                   | 필수   |                        |
| GF-016 | 사업 비교        | 여러 정부 지원사업의 지원조건, 지원금, 신청기간 등을 비교한다.                            | 선택   | 추후에                    |
| GF-017 | 유사사업 추천      | 사용자가 조회한 사업과 유사한 정부 지원사업을 추가 추천한다.                              | 선택   | 추후에                    |
| GF-018 | 실시간 응답       | SSE를 이용하여 Agent 진행상태와 LLM 답변을 실시간 Streaming한다.                  | 필수   |                        |
| GF-019 | 데이터 수집       | 기업마당, 나라장터, 정부부처 및 전문기관의 지원사업 정보를 수집한다.                         | 선택   | 추후에                    |
| GF-020 | 문서 수집        | 지원사업의 PDF, HWP, HWPX 등 첨부문서를 수집하고 관리한다.                         | 선택   | 추후에                    |
| GF-021 | 데이터 갱신       | 신규·변경·마감된 지원사업을 주기적으로 확인하여 데이터를 갱신한다.                           | 선택   | 추후에                    |
| GF-022 | Vector DB 관리 | 수집 문서를 Chunking·Embedding하여 Vector DB에 저장하고 재색인한다.              | 필수   |                        |
| GF-023 | RAG 품질 평가    | RAGAS를 이용하여 Faithfulness, Relevancy, Precision, Recall 등을 평가한다. | 필수   |                        |
| GF-024 | API 제공       | FastAPI 기반 REST API 및 Swagger/OpenAPI 문서를 제공한다.                 | 필수   |                        |
| GF-025 | 상담 이력        | 사용자 질문, AI 답변, 추천사업 및 Agent 실행 이력을 저장한다.                        | 선택   | 추후에                    |
| GF-026 | CI/CD        | GitHub Actions 또는 Jenkins를 이용하여 테스트·빌드·배포를 자동화한다.               | 필수   |                        |
